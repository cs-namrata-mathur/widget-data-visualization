# Installation
1. To install a widget, click **Content Hub** > **Discover**.
2. From the list of widgets that appears, search **Data Visualization** widget.
3. Click to open the **Data Visualization** widget card.
4. Click **Install** on the lower part of the screen to begin installation.

# Configuration

This widget has no configuration settings. Check the [Usage](./usage.md) section to configure Data Visualizations for your FortiSOAR™ environment.
